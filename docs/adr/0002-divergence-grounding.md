# ADR-0002：分歧报告要求引用原文，没核对上的降级而非丢弃

- 状态：已采纳
- 日期：2026-11-18
- 相关：`app/api/chat.py` 的 `verify_quote` / `filter_divergence`

## 背景

分歧报告由裁判模型生成，最初直接展示 JSON 结果。实测发现它会**编造引文**：
声称「回答说 X」，但原文里根本没有这句话。读者无法分辨真假。

## 决定

1. 裁判必须返回每方的**逐字引文**与出处编号
2. 用 `verify_quote` 在对应回答里回查：先去标点逐字比对，允许两成字符被改动的模糊匹配
3. 核对不上的那一条**降级到「未核实的分歧」**并标注原因，而不是静默删除

## 理由

- 编造的分歧比没有分歧危害更大：它会让人做错误判断
- 直接丢弃会让读者以为「没有分歧」，而实际是「分析失败」，同样误导
- 降级保留了信息，又把可信度标出来

## 为什么不直接用 LLM 复核

试过：加一层「这两句是否真的矛盾」的复核模型后，**误报降为 0，但真分歧也被杀掉一半**
（检出率从 91.7% 降到 67%）。原因是句子级复核看不到结论层面的矛盾。
所以复核默认关闭（`DIVERGENCE_VERIFIER` 留空），靠引文核对兜底。

## 后果

- 报告里可能同时出现「分歧」和「未核实的分歧」两段
- 弱模型（如 GLM-4-Flash）误报率仍达 100%：接地只能挡住编造引文，
  挡不住「真实引用 + 错误结论」。这一层需要更强的裁判模型，见 ADR-0003
